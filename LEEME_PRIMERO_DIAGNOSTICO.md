### PASO 2: Push del Código (5 min)

```powershell
cd "f:\MATRIZ DE REDES\social_media_matrix"
.\venv_stable\Scripts\Activate.ps1
git remote add origin https://github.com/TU_USUARIO/Matriz-de-Redes-Maristas.git

```

```
5. Branch: main
6. Main file: app.py
7. Click: "Deploy"
8. Espera 1-2 minutos
9. ¡Listo! Tu app está en vivo
```
